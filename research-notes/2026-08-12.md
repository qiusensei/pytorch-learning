# 写文件操作

因为添加了不同版本的CNN模型，不能简单的只是plot图片，也要学会打印结果。

这里我学习使用了最简单的pandas。

## pd.DataFrame

```python
import pandas as pd
experiment = "baseline"
pd.DataFrame({"experiment": experiment,
                  "epoch": epoch_num,
                  "loss": epoch_loss,
                  "acc": epoch_acc}).to_csv("results.csv", index=False)
```

在每个train.py里面命名了experiment，并使用pd.DataFrame打印到results.csv。

其中index=False是为了不让pandas自动写入一个索引。
