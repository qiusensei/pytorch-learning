# 特征图打印
今天打印了经过第一层卷积核处理之后的特征图，来帮助我理解CNN的原理。

## 加载模型

在加载模型之前，要先搭建一个模型的结构，也就是初始化一个net。

```python
net = model.MyCNN()
```

MyCNN()是我在model里面写的我的两层卷积核+一层全连接的神经网络模型。初始化net之后，再使用load_state_dict提取之前train保存的模型。

```python
net.load_state_dict(torch.load("checkpoints/mnist_cnn.pth"))
```

之后再提取一张dataset中的测试图片，手动进行一层Conv2d计算，会得到(1,32,26,26)的张量，也就是一共32个通道，每个通道都是26x26的特征图。

```python
feature_layer1 = net.net[1](net.net[0](images[0:1]))
```

这里有两个关键点

1. 不仅进行了net[0]，还进行了net.[1]也就是第一次Conv2d后面的一层ReLU。这里是为了把负数都变成0，也就是特征图只剩下0和正数，效果呈现出来的就是：背景黑色，特征（笔画）白色，对比明显，一目了然。
2. 这里用的是images[0:1]而不是images[1]是为了保留batch维度，这是因为Conv2d要求输入是4维，也就是常说的(B, C, H, W)。

> 使用images[0].unsqueeze(0)可以手动在0的位置插入一维，和这里的效果一样

## 画图

### 创建画布

```python
plt.figure(figsize=(12,6))
```

创建一个宽为12，长为6的画布，这里的figsize的单位是英寸。

### 循环打印

首先使用plt.subplot(rows, cols, index)，这个函数是把画布分成网格进行打印，其中index是打印位置，注意它是从1开始而不是从0开始。

先打印原图：

```python
plt.subplot(4, 9, 1)                        # 第 1 格:原图
plt.imshow(images[0, 0], cmap="gray")
plt.axis("off")
```

接下来要循环打印这32张图片在画布里，就要获取循环次数，也就是第1维的通道数量。

```python
for i in range(feature_layer1.size(1)):
  	plt.subplot(4,9,i+2)
    plt.imshow(feature_layer1[0,i].detach(),cmap="gray")
    plt.axis("off")
```

plt.imshow(img, camp=)则是打印img，并用gray设置成打印灰度。

这里使用了.detach()是因为matplotlib打印的时候会把张量转换成numpy，但是我们的feature_layer1的张量内部是记录着梯度信息的，也就是前面提到的requires_grad=True，因此要使用detach让feature_layer1脱掉这些梯度之后，才能被顺利转换成numpy数组并打印成图片

plt.axis被设置成off也就是不需要刻度。

### 图片保存

首先使用plt.tight_layout()自动调整子图间距，避免重叠，之后使用savefig保存图片。

```python
plt.tight_layout()
plt.savefig("plots/feature_layer1_withRAW.png",dpi=150)
```

## 结果分析

去掉ReLU后，某些特征图从“全黑”变成“白底黑字”（相当于恒等映射），这说明那个kernel没学到任何特征，只是进行了复制像素；全黑说明该kernel对这张图无反应。ReLU则是让这样的kernel生成的特征图进入下一层的时候，所有值都是0，也就不会对下一层产生任何贡献。

### 结论

1. 不是所有kernel都有用,训练"够用就好"。
2. ReLU在引入非线性的同时,顺带过滤了无效信息。
