# 今日目标

今天打算对ResNet的学习进行收尾，分析一下模型在训练和测试时遇到的问题。

# 实验 A: E4 掉点验证

在seed=42进行训练时，acc曲线在E4的时候会出现大幅下降，为了判断是随机性还是模型本身导致的，分别又在seed=1000和seed=919上进行了实验，919上再次出现掉点，但是1000上没有掉点，但它们三者的acc都呈现锯齿状，说明本身是锯齿问题。

# 实验 B:ResNet vs baseline CNN

| 数据                           | ResNet（86826参数） | CNN（34826参数） | 差距                   |
| ------------------------------ | ------------------- | ---------------- | ---------------------- |
| last均值（E10acc的3-seed平均） | 0.9819              | 0.9898           | CNN领先+0.79点         |
| best均值（每seed最高acc平均）  | 0.9899              | 0.9902           | CNN领先+0.03（基本持平 |
| 波动范围（last的max-min）      | 0.0130              | 0.0020           | ResNet波动6.5倍        |
| E1起点均值                     | 0.9683              | 0.9801           | CNN领先+1.18点         |

2.5倍的参数量并没有出现性能提升，说明在ResNet并不是很适合解决MNIST这个简单问题。

#  锯齿现象的归因实验(lr=1e-4)

锯齿问题可能是由于lr偏大导致的，因此在lr=1e-4下进行了实验，可以看到锯齿消失了，但是代价是训练变慢，10个epoch并不一定能训练到最优的模型，下一步可以稍微调大一些lr进行实验。比如在4e-4，5e-4下进行实验。

# 方法论:best vs last / selection bias

不应该在测试集上挑best，测试集只用来展示模型性能，应该从train集合里切出一份用来选择best的模型，最后使用test数据集汇报这个模型的性能，test仅用来展示性能。

如果要改脚本，首先需要改掉dataset的部分，其次是要改掉训练循环的部分，并且，保存模型的时候要依据train中切分出来的val数据集挑选best模型，当然所有的数据打印部分也需要做相应修改。
